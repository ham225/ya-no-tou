プライバシーポリシー

本アプリ「矢の塔 (Ya no Tou)」(以下「本アプリ」)におけるユーザー情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。

最終更新日: 2026年5月16日

1. 取得する情報

本アプリは、ユーザー登録機能を持たず、ユーザーの氏名・メールアドレス・電話番号などの個人を直接特定する情報を取得しません。

ただし、後述する広告配信サービスを通じて、以下の情報が取得・利用される場合があります。

  • 広告ID(Advertising ID)
  • 端末の種類・OSバージョン・言語設定などの一般的な端末情報
  • IPアドレス
  • 本アプリの利用状況(プレイ時間、画面遷移など)

2. 広告配信について

本アプリは、第三者配信の広告サービスとして Google の AdMob を利用しています。

AdMob は、Cookie や広告ID を使用してユーザーの興味に応じた広告を配信することがあります。これらの情報は AdMob のプライバシーポリシーに従って取り扱われます。

Google のプライバシーポリシー: https://policies.google.com/privacy

広告 ID は、端末の設定からリセット・無効化することができます。

3. 取得情報の保存先

本アプリは、ベスト記録(到達ステージ・撃破数)とミュート設定をユーザーの端末内のローカルストレージに保存します。これらの情報は外部サーバーには送信されません。

4. 第三者への提供

本アプリは、上記広告配信サービスを除き、取得した情報を第三者に提供しません。
