## 詳細な説明 (長い説明、4000文字以内)
```
■ 矢の塔 (Ya no Tou) について

「矢の塔」は片手で遊べる、縦画面のスクロール型ローグライクゲームです。
画面をドラッグしてキャラを動かし、指を離すと自動で矢を放つシンプル操作。
動きながら撃てないので「いつ止まって撃つか」が攻略の鍵になります。

■ 特徴

・10ステージ + ボス戦
  入口から始まり、速き者・射手の間・分裂洞・爆弾魔・盾持ちの間などを攻略し、
  最終ステージのタワーマスターを倒して全クリアを目指します。

・10種類の敵
  普通の雑魚から、ジグザグに迫る敵、止まって弾を撃つ射手、倒すと分裂する敵、
  接触で爆発する爆弾魔、加速して追いかけてくる追跡者まで。
  ステージごとに違う組み合わせで挑んできます。

・ステージクリアで強化を選ぶローグライク要素
  クリアごとに3つの強化からランダムに1つ選択。攻撃力UP、連射UP、多重射撃、
  貫通、最大HP、回復、機動力、周回の矢など、組み合わせで毎ラン違う戦い方ができます。

・ラン制
  ゲームオーバーで強化はリセット。1からまた挑戦して、新しいビルドを試そう。

■ 操作

・画面のどこでもドラッグして移動
・手を離すと自動で矢を撃つ
・敵を全滅させると次のステージへ
・効果音オン/オフは右上のボタン

■ こんな人におすすめ

・短時間で遊べる片手ゲームを探している
・ローグライクの「ビルドを組む」楽しさが好き
・Archero みたいな自動射撃ゲームが好き
```
