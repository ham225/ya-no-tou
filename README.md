# 矢の塔 (Ya no Tou)

スクロール型ローグライクゲーム(アーチェロー風)。スマホ向け。

## 開発

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開く。

## 技術スタック

- ゲームエンジン: Phaser 3
- ビルドツール: Vite + TypeScript
- ネイティブ化: Capacitor 6 (Phase 6で追加予定)
- プラットフォーム: Android (Google Play)
